# shipi18n-demo — DEPRECATED

> [!IMPORTANT]
> This repo demoed the **hosted Shipi18n API, which has been shut down.** It is no longer maintained.

Shipi18n is now open source and bring-your-own-LLM. See the current tools:

- **Source & docs:** https://github.com/Shipi18n/shipi18n
- **Try it:** `npx @shipi18n/cli check ./locales -s en` (structural check, no API key), or the free
  [in-browser checker](https://shipi18n.com/free-tools/i18n-checker).

The hosted-API demo previously shown here no longer applies.
